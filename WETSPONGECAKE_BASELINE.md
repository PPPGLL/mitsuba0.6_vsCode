# WetSpongeCake baseline

This branch preserves the implementation state before correcting the particle
number density, particle-size scaling, and anisotropic Hapke `EL` expression.

- Base commit: `6b9fac12` (`main`)
- Snapshot branch: `wetspongecake-baseline`
- Snapshot date: 2026-10-10
- The snapshot intentionally retains the pre-fix transport behavior for
  regression comparisons.

Local dependency archives, rendered images, and large generated particle-scene
XML files are excluded from Git. They are not required to recover the research
source code and should be regenerated or stored as external experiment data.
